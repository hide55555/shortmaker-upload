プライバシーポリシー(ショートメーカー投稿)

制定日: 2026年11月21日

1. 対象

このポリシーは、個人用ツール「ショートメーカー投稿」(以下「本アプリ」)に適用されます。本アプリは開発者本人だけが、自分の YouTube チャンネルのために使います。

2. 取得する情報

本アプリは、Google アカウントでの許可により、次の権限だけを使います。

  • YouTube へ動画をアップロードする権限(youtube.upload)
  • 自分のチャンネル情報と、アップロードした動画の状態を読む権限(youtube.readonly)

扱う情報は、チャンネル ID・チャンネル名・アップロードした動画の ID と処理の状態、およびログインを保つための認証情報だけです。

3. 使い道

開発者本人のチャンネルへ動画を非公開でアップロードし、その処理が終わったかを確かめるためだけに使います。

4. 保存と第三者への提供

  • 情報は開発者本人のパソコンの中だけに保存し、外部のサーバーへは送りません。
  • 第三者への提供・販売はしません。広告や分析には使いません。
  • 本アプリによる Google API から受け取った情報の使用と移転は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

5. YouTube と Google の規約

本アプリは YouTube API Services を使用しています。あわせて YouTube 利用規約 と Google プライバシーポリシー をご覧ください。

6. 許可の取り消しと削除

許可はいつでも Google アカウントの「サードパーティのアプリとサービス」から取り消せます。保存した情報は、開発者本人のパソコンからファイルを消すことで削除します。

7. 変更

このポリシーを変更するときは、このページで知らせます。

Privacy Policy (English summary)

Shortmaker Uploader is a personal tool used only by its developer. It uses only the YouTube scopes youtube.upload and youtube.readonly to upload the developer's own videos as private videos to the developer's own channels and to check their processing status. It handles only channel ID, channel name, uploaded video IDs and their status, and the credentials needed to stay signed in. All data stays on the developer's own computer and is never sent to other servers, sold or shared, or used for ads or analytics. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google Account third-party connections.
