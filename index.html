ショートメーカー投稿

Shortmaker Uploader

このアプリについて

「ショートメーカー投稿」は、開発者本人が自分の YouTube チャンネルへ、自分で作ったショート動画を「非公開」でアップロードするための個人用ツールです。一般の方への提供はしていません。

  • 動画・題名・説明文・サムネイルを、YouTube へ非公開でアップロードします。
  • 公開・動画の削除・コメントの投稿は行いません(公開は本人が YouTube Studio で行います)。
  • YouTube API Services を使用しています。

About

Shortmaker Uploader is a personal tool used only by its developer to upload the developer's own short videos to the developer's own YouTube channels as private videos (video, title, description and thumbnail). It never publishes, deletes or comments. It is not offered to the public. This tool uses YouTube API Services.
